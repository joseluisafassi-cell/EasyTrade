# EasyTrade — Trading Floor AI

Oficina de trading con agentes de IA: cada agente es un empleado (archivo en `agents/`) cuyo rol,
instrucciones y tareas puedes editar. Solo analiza; nada sale sin tu aprobación.

- `AGENTS.md`: reglas para Codex (seguridad y stack).
- `PLAN.md`: plan por fases con criterios de aceptación.
- `agents/`: los 8 empleados iniciales. `config/`: límites de riesgo y umbrales (por rellenar).
